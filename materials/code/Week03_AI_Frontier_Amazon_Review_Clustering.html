<h1 id="Week-03-%7C-AI-Frontier:-Review-Clustering-with-Text-Embeddings">Week 03 | AI Frontier: Review Clustering with Text Embeddings¶</h1><p>Marketing Strategy — Managing Customer Heterogeneity</p> <p>Business question: Can we discover recurring themes in customer reviews without defining survey attributes in advance?</p> <p>In the Boats workshop, we represent customers using structured survey responses. Here, we represent unstructured review text using a pretrained neural network, then apply the familiar K-means algorithm.</p> <p>Workflow: Raw reviews → Data exploration → Sentence embeddings → K-means → Interpretation.</p> <h3 id="How-to-run">How to run¶</h3>
  1. Open this .ipynb in Google Colab using File → Upload notebook, or in Jupyter.
  2. Run the cells from top to bottom. Internet access is needed to install the package and download the public data and model the first time. No API key or paid inference service is required. A CPU is sufficient; a GPU is optional.
  3. The notebook automatically reads the original CSV from GitHub, or uses a local fine_food_reviews_1k.csv if present. In Colab you can upload that file using the Files sidebar before running the loading cell.
<p>Data: Amazon Fine Food Reviews — 1,000-review teaching subset. The original Cookbook clustering example inspires this exercise, but we generate new embeddings locally with Sentence Transformers rather than using precomputed OpenAI vectors. This is review clustering, not customer-level segmentation.</p>

A missing title is allowed, but an empty review body is excluded. Ratings outside 1–5 are treated as missing for profiling only. def clean_text(value):
    if pd.isna(value):
        return ""
    text = html.unescape(str(value))
    text = re.sub(r"<[^>]+>", " ", text)
    return re.sub(r"\s+", " ", text).strip()

df = raw.copy()
df["clean_title"] = df["Summary"].map(clean_text)
df["clean_body"] = df["Text"].map(clean_text)
df = df.loc[df["clean_body"].ne("")].reset_index(drop=True)
df["review_text"] = (
    df["clean_title"].where(df["clean_title"].eq(""), df["clean_title"] + ". ")
    + df["clean_body"]
).str.strip()

df["Score"] = pd.to_numeric(df["Score"], errors="coerce")
df.loc[~df["Score"].isin([1, 2, 3, 4, 5]), "Score"] = np.nan
df["review_date"] = pd.to_datetime(df["Time"], unit="s", errors="coerce", utc=True)
df["word_count"] = df["clean_body"].str.split().str.len()

print(f"Reviews retained: {len(df):,} of {len(raw):,}")
display(df[["Summary", "review_text", "Score"]].head(3))

<p>Class discussion: Are most reviews positive or negative? Do all reviews contain the same amount of information? Could ratings alone tell us why customers liked or disliked a product?</p> <h2 id="3.-Generate-text-embeddings">3. Generate text embeddings¶</h2><p>A pretrained Sentence Transformer maps a text into a fixed-length numerical vector. We use all-MiniLM-L6-v2, which produces 384-dimensional embeddings for English text. We do not train or fine-tune the model.</p> <p>We first illustrate semantic similarity, then encode the entire review dataset. Normalizing vectors to unit length makes their dot product equal to cosine similarity and puts the reviews on a common scale before clustering.</p> <p>Model limitation: This model normally processes at most 256 subword tokens per text; longer combined reviews are truncated by default. Word counts above are not token counts. For this introductory demonstration we accept truncation; a production project could split long reviews into chunks and aggregate their embeddings.</p>

<h2 id="4.-Cluster-analysis">4. Cluster analysis¶</h2><p>K-means groups the normalized embedding vectors by minimizing within-cluster squared Euclidean distances. It does not use review ratings, product IDs, or manually supplied theme labels.</p> <h3 id="4.1-Fit-K-means">4.1 Fit K-means¶</h3><p>Start with four clusters, following the teaching example in the Cookbook. Four is an illustrative choice, not an empirically established optimal number. Since the embedding model differs from the original example, the resulting clusters may also differ.</p>
In [12]:

<h2 id="Takeaways-for-marketing-strategy">Takeaways for marketing strategy¶</h2>
  • Representation is the AI frontier: The clustering algorithm is still K-means, but a pretrained model can transform unstructured feedback into machine-readable features without a fixed survey questionnaire.
  • Interpretation remains managerial: The algorithm may separate product categories, sentiment, product features or customer concerns. Read the reviews and validate the themes before making decisions.
  • Unit of analysis matters: One review is not necessarily one unique customer. A review cluster should not automatically be described as a customer segment.
  • Validation matters: The sample is small and dated, the model truncates long reviews, and a cluster's mean rating is descriptive rather than evidence of causation. Test stability across samples, models and choices of K before deployment.
