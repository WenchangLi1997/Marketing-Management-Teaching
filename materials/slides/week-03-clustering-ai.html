Marketing Principle #1: All customers differ

Prepared by Yixing Chen and Wenchang Li

Two analytical pathways

Structured and unstructured customer data

Case workshop

Cluster customers using numeric purchase variables in SPSS.

AI frontier

Embed customer language and cluster the resulting vectors in Python.

Both methods produce groups. Neither method decides whether the groups are strategically useful.

Cluster analysis

What the algorithm is trying to do

Create groups with small differences within each group and large differences between groups.

  • Each row represents a customer.
  • Each selected column represents a segmentation variable.
  • The distance measure defines what “similar” means.

Preparation

Scale and skew can dominate the solution

Log transformation

Reduces the influence of highly skewed spending distributions.

Standardization

Places variables on comparable scales before calculating distances.

Cleaning is part of the model. A cluster solution reflects every preprocessing choice.

Choosing the number of clusters

Use evidence, then apply judgment

Statistical separation

Look for a clear improvement in compactness or separation.

Stability

Check whether modest changes in data or initialization alter the solution.

Managerial value

Ask whether the groups imply different actions and can be reached.

SPSS workflow

Hierarchical exploration, then k-means refinement

  1. Import and inspect the data.
  2. Log-transform and standardize spending variables.
  3. Use hierarchical clustering to inspect plausible values of k.
  4. Run k-means for selected values of k.
  5. Profile, name, and evaluate the clusters.

Workshop decision

What would make a useful segment?

  • A distinctive pattern of category spending.
  • A plausible customer need or operating model behind that pattern.
  • An action the distributor could change for the segment.
  • A practical way to identify similar customers later.

Cluster profiling

Numbers first, names last

  1. Compare cluster means on the variables used to create the solution.
  2. Use variables not included in clustering to describe the groups.
  3. Read representative customer records.
  4. Name a cluster only after its pattern and business meaning are clear.

AI Frontier 1

Embedding-based segmentation

An embedding converts customer language into a numeric vector that represents patterns of meaning.

The vector can be clustered, but the analyst must return to the original text to interpret the groups.

Text workflow

From customer comments to segments

Embed

Convert each customer response into a vector.

Cluster

Group normalized vectors according to semantic similarity.

Interpret

Read exemplars, name themes, and test managerial usefulness.

Python workflow

What the starter script does

  1. Loads anonymized customer comments.
  2. Creates sentence embeddings with a configurable model.
  3. Compares candidate values of k using silhouette scores.
  4. Fits k-means to normalized embeddings.
  5. Exports cluster assignments and representative comments.

Interpretation risks

Semantic similarity is not market value

  • Clusters may reflect sentiment or writing style.
  • Short comments may lack decision context.
  • Model choice changes the geometry.
  • Text may contain personal or sensitive information.
  • Small clusters may be unstable.
  • A theme may be interesting but impossible to target.

Submit a short segmentation memo

  • One marketing action for the priority cluster.
  • One limitation of the analysis.

Takeaways

Clustering proposes structure; strategy gives it meaning

  • Preprocessing and distance choices shape every cluster solution.
  • The best value of k balances separation, stability, and actionability.
  • Embeddings extend segmentation to unstructured language.
  • Managers must validate whether the resulting groups support different decisions.
