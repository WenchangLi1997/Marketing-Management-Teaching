Marketing Management · Week 3

Marketing Principle #1: All customers differ
Yixing Chen and Wenchang Li

Today’s workflow

  1. Translate customer needs into measurable survey or behavioral variables.
  2. Reduce redundant questions when several items measure the same underlying need.
  3. Use hierarchical clustering and k-means to identify candidate segments.
  4. Profile the groups and evaluate whether they support different marketing actions.
  5. Extend the same logic to customer language using text embeddings.

From research to action

The segmentation analytics chain

Qualitative research identifies possible needs. Measurement captures them. Statistical analysis proposes groups. Managerial judgment determines whether the groups matter.

Measurement design

Variables used to create segments

  • Importance of purchase benefits
  • Usage situations and functional needs
  • Preferences and willingness to trade off attributes

Variables used to describe segments

  • Demographics and firm characteristics
  • Media behavior, channel, or geography
  • Past purchases and customer value

Keep the variables that define groups conceptually separate from variables used later to identify or reach them.

Factor analysis

  • Customer surveys often contain several questions that measure closely related purchase attributes.
  • Factor analysis summarizes correlated questions with a smaller number of latent dimensions.
  • The reduction can limit redundancy and prevent one underlying need from receiving excessive weight in clustering.
  • Factor scores can become the inputs to cluster analysis when the survey contains many correlated items.

Example: convenience, schedule flexibility, and travel time may all reflect an underlying accessibility factor.

Three analyses, three questions

Factor analysis

Which questions measure the same underlying need?

Cluster analysis

Which customers have similar patterns of needs or behavior?

Classification

Which observable characteristics predict membership for a new customer?

The methods solve different problems and appear at different stages of the STP process.

Cluster analysis

Grouping similar customers

A clustering algorithm searches for groups with relatively small differences within groups and larger differences between groups.

What the algorithm sees

  • Each row represents one customer or decision-making unit.
  • Each selected column represents a segmentation variable.
  • A distance measure converts differences between rows into a numerical definition of similarity.
  • The algorithm does not know the business meaning of a variable or the cost of acting on a segment.

Good clustering: low within-cluster distance and high between-cluster distance

Distance defines similarity

  • Euclidean distance is common for continuous, standardized variables.
  • Variables with large numerical ranges can dominate the calculation if the analyst does not standardize them.
  • Highly correlated variables can repeatedly count the same underlying difference.
  • Changing the distance measure or variable set can materially change the resulting segments.

Data preparation

  1. Check missing values, impossible values, and duplicated records.
  2. Inspect distributions and identify influential outliers.
  3. Transform strongly skewed variables when appropriate.
  4. Standardize variables measured on different scales.
  5. Document which variables entered the clustering step and which remained available for profiling.

Preprocessing choices become part of the segmentation model.

Skew and scale

Log transformation

Spending variables often contain a long right tail. A log transformation reduces the influence of extreme values while preserving rank.

Standardization

Z-scores place variables on a common scale so that a category measured in large monetary units does not dominate distance.

z = (x − mean) / standard deviation

Hierarchical clustering

  • The procedure begins with every customer as a separate group and repeatedly merges similar groups.
  • Ward’s method chooses merges that create a relatively small increase in within-cluster variation.
  • A dendrogram records the sequence and relative cost of the merges.
  • Large jumps in the merger distance suggest candidate points at which to stop combining groups.

Hierarchical clustering is useful for exploration, but the dendrogram does not determine the correct number of segments by itself.

Reading a dendrogram

  • Trace the tree from individual observations toward a single combined group.
  • Look for a relatively large increase in distance between consecutive mergers.
  • Compare solutions immediately before and after the jump.
  • Inspect what changes when moving from three to four clusters or from four to five.
  • Prefer a simpler solution when the additional cluster adds little statistical or managerial value.

K-means clustering

  1. Select a candidate number of clusters, k.
  2. Assign initial cluster centers.
  3. Assign every customer to the nearest center.
  4. Update the centers and repeat until assignments stabilize.

K-means is efficient and interpretable, but it requires the analyst to choose k and can depend on initialization.

Choosing the number of clusters

  • Separation: customers should be closer to their own group than to alternatives.
  • Stability: modest changes in initialization, sample, or preprocessing should not destroy the solution.
  • Parsimony: an additional group should contribute a meaningful distinction.
  • Managerial value: the groups should imply different value propositions or actions.
  • Identifiability: the firm needs a practical way to recognize new members.

Silhouette score

  • For each customer, compare average distance to its own cluster with average distance to the nearest alternative cluster.
  • Values near 1 indicate a well-separated observation.
  • Values near 0 indicate an observation close to a boundary.
  • Negative values suggest that another cluster may fit the observation better.
  • The average score helps compare candidate values of k, but it does not measure business usefulness.

Cluster profiling

  1. Compare cluster means on the variables used to create the solution.
  2. Use holdout variables to describe demographics, channels, economics, or behavior.
  3. Read representative records near each cluster center.
  4. Identify the need pattern that distinguishes each group.
  5. Name the cluster only after its profile and business meaning are clear.

Statistical groups versus market segments

  • A compact cluster may have no different need that the firm can address.
  • A distinctive group may be too small or expensive to reach.
  • A profitable segment may require capabilities the firm does not possess.
  • A stable group may disappear when technology, competition, or customer preferences change.

Cluster analysis proposes structure. Strategy determines whether the structure deserves investment.

Wholesale Customers

The dataset records annual spending by 440 customers of a wholesale distributor.

Profiling variables

SPSS workflow

  1. Import the CSV and verify variable types, ranges, and missing values.
  2. Compute log-transformed spending variables and standardized scores.
  3. Run hierarchical clustering with Ward’s method and inspect the dendrogram.
  4. Compare three-cluster and four-cluster solutions.
  5. Run k-means for the selected value of k.
  6. Save cluster membership and profile the groups using original spending values, Channel, and Region.

Questions for the SPSS output

  • Which spending categories contribute most to the separation?
  • Does one cluster mainly capture extreme overall spend rather than a distinct purchasing pattern?
  • How different are the group sizes?
  • Do Channel and Region reveal a practical way to identify or reach the groups?
  • What business explanation could produce each profile?

Workshop decision

Recommend one segmentation solution

  • Choose the number of clusters and explain the statistical evidence.
  • Describe the need or operating pattern represented by each group.
  • Identify one group that deserves a different offer or service model.
  • State how the distributor could recognize similar customers in the future.

DentMax analytics process

  • Trade-show RFID data captured the time dentists spent at competing booths.
  • Survey data captured imaging needs, media trust, and preferences.
  • Past purchase behavior provided additional evidence about commercial relationships.
  • Cluster analysis identified Loyalists, Switchables, Generalists, and Apathetics.
  • Targeting then required a separate judgment about attractiveness and DentMax’s relative strength.

DentMax targeting implications

  • Loyalists: strong fit with image quality and diagnostic flexibility. Retention and advocacy are plausible priorities.
  • Switchables: attractive source of growth if DentMax can credibly improve software integration and technical support.
  • Generalists: large segment, but price sensitivity conflicts with a premium position.
  • Apathetics: low involvement reduces the likely return from specialized investment.

AI Frontier 1

Embedding-based segmentation

Embeddings make it possible to apply segmentation logic to open-ended customer language rather than only predefined numeric variables.

What an embedding represents

  • A language model converts each customer comment into a numeric vector.
  • Comments with similar patterns of meaning tend to appear closer together in the vector space.
  • The dimensions do not have simple labels such as price sensitivity or convenience.
  • The analyst must return to the original comments to interpret, name, and validate the groups.

Structured and text-based segmentation

DecisionStructured dataCustomer language
RepresentationSelected survey or behavioral variablesEmbedding vectors created from text
SimilarityDistance across standardized variablesSemantic proximity across normalized vectors
InterpretationCluster means and descriptorsRepresentative comments and recurring themes
Main riskVariables omit important needsClusters reflect style, sentiment, or model choice

Embedding workflow

  1. Define the customer-level text unit and remove direct identifiers.
  2. Create an embedding for every response using a consistent model.
  3. Normalize vectors when the distance interpretation requires it.
  4. Compare candidate values of k and fit the clustering model.
  5. Read representative comments from each group and assign provisional labels.
  6. Test whether the groups differ on outcomes, value, or feasible marketing actions.

What the Python script does

  • Loads the anonymized customer feedback file.
  • Creates sentence embeddings with a configurable model.
  • Normalizes the vectors and compares candidate values of k with silhouette scores.
  • Fits k-means and saves a cluster assignment for every response.
  • Exports representative comments near each cluster center for interpretation.

The script provides a reproducible starting point. It does not automatically produce strategically valid segments.

Interpreting text clusters

  • Read both central examples and unusual comments within each group.
  • Check whether the cluster reflects a need, a use case, sentiment, writing style, or vocabulary.
  • Compare cluster membership with observable outcomes such as satisfaction, retention, or product usage.
  • Ask whether the firm can identify and reach similar customers outside the research sample.
  • Treat labels as hypotheses that require human review and validation.

Risks and safeguards

Analytical risks

  • Model choice changes the geometry
  • Short comments lack context
  • Small clusters may be unstable
  • Coherent themes may have no economic value

Governance safeguards

  • Remove personal and sensitive information
  • Document the model and preprocessing
  • Review representative comments
  • Test stability and downstream outcomes

Workshop deliverable

Short segmentation memo

  • Recommended number of clusters and supporting evidence
  • Profile and name for each cluster
  • One marketing action for the priority group
  • One method for identifying similar customers later
  • One limitation that could change the recommendation

Week 3 recap

  • Measurement and preprocessing choices determine the meaning of similarity.
  • Hierarchical clustering helps explore candidate structures. K-means refines a chosen solution.
  • The number of clusters should balance separation, stability, simplicity, and managerial value.
  • Profiling and targeting require evidence beyond the variables used to create the groups.
  • Embeddings extend segmentation to customer language, but interpretation and validation remain managerial responsibilities.
